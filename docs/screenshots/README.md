# Screenshot examples

These are actual native application framebuffer captures, taken with a separate
demo library. The eight botanical illustrations were drawn procedurally for
this guide; their original vector sources are in [demo-art](demo-art/).
No images from the user's personal collection or research datasets are shown.

The screens illustrate the controls and workflow, not retrieval accuracy.
Search results were produced by the bundled model on this small demo collection.
Library shows a real indexing job and its live speed/remaining-time indicators.
The capture driver only sets demo inputs, navigates pages and scrolls the app;
it does not draw a substitute interface or alter the captured pixels.

Click a screenshot in the main README or guide to view the full-size image.
