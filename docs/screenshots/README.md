# Desktop screenshots

These captures show the Rust app with a separate demo library. The eight botanical illustrations were drawn procedurally for the guide; their SVG sources are in [demo-art](demo-art/).

`search.png` shows a reference and text query. `refine.png` shows the negative-image controls. `library.png` captures indexing progress, including speed and estimated time remaining. `settings.png` shows display controls, and `viewer.png` shows the image preview.

The captures come from the app's framebuffer. The capture driver selects demo inputs and scrolls the interface; it doesn't draw a replacement UI or edit the captured pixels. No personal collection or research-dataset images appear here.

Results come from the bundled model searching this demo library. The screenshots demonstrate the controls, not retrieval accuracy. Click any screenshot in the README or guide for its full-size image.
